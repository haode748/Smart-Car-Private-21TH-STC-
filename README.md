## 1. 项目概述

本项目采用 **STC32G144K（32 位 8051 内核，C251 架构）** 作为主控芯片，针对高速摄像头寻迹场景设计。

- **视觉感知**：总钻风灰度摄像头（MT9V03X，188×120）+ 动态阈值二值化 + 边缘连续搜线算法。
- **运动底盘**：后轮双直流有刷电机（增量式 PID 闭环 + 阿克曼转向差速模型）；前轮数字舵机（位置式 P²ID 闭环 + 陀螺仪角速度阻尼）。
- **位姿解算**：IMU660RB 六轴惯导模块，提取 Z 轴偏航角速度并积分，用于环岛姿态估算与抗扰动补偿。
- **特色功能**：集成环岛状态机、十字补线逻辑，以及**靶心扫描识别与多路激光瞄准射击**。
- **调参交互**：IPS200 液晶屏幕可视化交互菜单，支持板载按键实时调参及 EEPROM 非易失性存储。

### 构建状态与代码说明

- **编译状态**：Keil μVision 构建 `0 Error(s), 0 Warning(s)`
- **固件体积**：`Code = 103,505 B` / `XDATA = 33,641 B`
- **待完善项**：
  - 十字识别逻辑已在 `image.c` 中落地，独立文件 `cross.c` 预留待重构。
  - 直道提速与斑马线识别算法已封装完毕，默认处于注释停用状态，需实车验证后开启。

## 5. 核心控制与算法实现

### 5.1 图像处理管线 (`image.c`)

图像任务是全车控制的引导源头，数据处理流经以下标准阶段：

1. **自适应动态阈值分割 (`get_reference_point`)**：  
   在图像底部固定区域统计局部背景亮度，实时解算出黑白分割阈值：
   Threshold = f(white_max_point, white_min_point)
   相较于固定阈值，该方案有效抵御了赛场光照不均与反光干扰。
2. **引导列搜寻与边缘追踪 (`search_reference_col` / `search_line`)**：  
   以中轴引导列为基准，自近景向远景按行扫描，利用对比度梯度定位左右边缘坐标，记录至 `left_edge_line[]` 与 `right_edge_line[]`。
3. **丢线统计与粗处理**：  
   记录单侧连续丢线行数（`Left_Lost_Time` / `Right_Lost_Time`），供后续十字与环岛算法判定赛道断续状态。
4. **视距前瞻与加权偏差解算 (`error_calcul`)**：  
   基于赛道边缘反求物理中线，通过多行加权平均解算出水平偏航误差 `Img_error`。

> ℹ️ **坐标系定义**：图像纵向分辨率 H=120（行索引 0 为近景车头处，119 为远景极限）；横向分辨率 W=188。

### 5.2 运动控制系统 (`pid.c`)

主控使用整型与单精度浮点混合运算，兼顾 C251 架构的处理吞吐率与运算精度。

#### 转向闭环：非线性误差二次项控制 (P²ID)
针对大曲率弯道响应慢、小曲率直线易振荡的特点，方向环引入了误差二次项与陀螺仪微分阻尼：

u_turn = Kp * e + sgn(e) * kp2 * e^2 + Kd * delta_e + kd2 * gyro_z

```c
// 实际工程代码实现逻辑
car_dir = Postion_P2ID_Cal(&Pid_turn, Img_error - 11, groyz, kp2, kd2);
```
- **机械超前补偿**：`Img_error - 11` 抵消了舵机连杆的机械滞后，促使车辆提前入弯。
- **动态阻尼衰减**：引入 Z 轴角速度 gyro_z（`groyz`），有效抑制转向超调与高速蛇形抖动。

#### 速度闭环：增量式 PID 与阿克曼主动差速
左右轮采用独立的增量式数字 PID 控制器，并在转弯工况下引入基于阿克曼几何模型的差速补偿：

v_L = v_target * (1 - (B * tan(delta)) / (2 * L) * Kp)
v_R = v_target * (1 + (B * tan(delta)) / (2 * L) * Kd)

*式中 L 为车辆轴距（`LDISTANCE = 200mm`），B 为轮距（`BORDWIDTH = 155mm`），delta 为当前前轮等效转向角。*

### 5.3 环岛全流程状态机 (`cycle.c`)

环岛识别结合了**特征角点扫描**、**边界斜率重塑**与**偏航角姿态积分**，包含严密的跃迁保护机制：

```
[0: 正常巡线] ───► [1: 发现环岛拐点] ───► [2: 入环姿态引导]
                                              │
[5: 出环边界重构] ◄── [4: 环内巡线] ◄─── [3: 环内切角修正]
       │
       └──► [8: 角度积分复位] ───► [9: 环岛处理完成]
```

- **特征拐点捕捉**：调用 `Find_Left/Right_Up/Down_Point()` 寻找环岛喇叭口处的跃迁极值点。
- **斜率补线重构**：`K_Add_Boundry_Left/Right()` 在检测到有效单侧断裂时，利用入环切线强制引导图像路径，防止因视野断边造成的误判。
- **航向辅助判定**：进入环岛后（状态 > 2）启动陀螺仪 Z 轴积分（`get_car_angle()`），将转角累计至 ±360°，作为出环与状态机退出的硬性安全校验边界。

### 5.4 靶心检测与激光打击 (`bullseye.c`)

- **视觉定位**：在视野中前瞻区域（第 45~75 行）设立 ROI，横向遍历连贯低灰度像素簇，通过质心算法提取出靶心二维坐标 (center_x, center_y)。
- **射击时序**：判定锁定靶心后置位 `bullseye_flag`，调用 `JGD()` 触发指定激光阵列引脚，并通过控制定时器自减实现安全脉冲发光，防止激光头过载损坏。
- **停车判定**：命中计数器累计达到预设阈值（`count_flag == 2`）时，系统自动切入 `Car_Mode = Lock` 停车模式。

## 9. 板载参数调节系统

为保证现场调试效率，系统支持基于板载按键与屏幕的直接调参，并持久化写入片上 Flash 模拟的 EEPROM 中。

```
[KEY1: 界面切换] ───► ( 图像显示监视 ◄───► 核心参数列表 )
[KEY2: 项目上移] / [KEY3: 项目下移]
[KEY4: 参数递减] / [KEY5: 步进递增并触发自动持久化保存]
```

### 9.1 参数映射与存储规范

- **存储物理基地址**：`0x03D000`
- **数据结构校验机制**：采用 `SavedParams` 结构体打包，头部写入魔数（`Magic = 0xA5A5`），尾部挂接双字节累加和（`Checksum`）。系统上电自检失败时自动恢复出厂默认值，防止未初始化内存破坏运行安全。

## 10. 赛道元素处理策略

| 赛道特征 | 识别算法模型 | 执行决策动作 | 交付状态 |
| :--- | :--- | :--- | :--- |

| **大型环岛** | 上下拐点断续检测 + 连续性特征校验 | 斜率补线强行锁道 + 航向积分复位退出 | 稳定投产 |

| **十字路口** | 双侧同时丢线 + 边界开阔突变 | 基于历史斜率作补线对穿 | 基本可用 |
| **斑马线** | 周期性黑白行宽突变统计 (`zebra.c`) | 进站减速 / 终点刹车控制 | 预留接口（默认关闭） |

## 12. 常见问题排查 (FAQ)

#### Q1: 编译提示缺少 `stc32g144k246.h` 或编译器内部错误？
> **排查方法**：Keil 未安装 PK251 工具包。该芯片需专用 32 位 C251 编译器，请检查 Keil 安装目录中是否存在 `C251` 文件夹，并确认工程配置中 Toolchain 路径正确。

#### Q2: 舵机出现高频抖动或异常发热？
> **排查方法**：
> 1. 微分阻尼项设置过激：适当减小 `kd2` 或 `Pid_turn.Kd`。
> 2. 检查供电与地线噪声：高负载时降压模块输出纹波过大可能导致 PWM 捕获抖动。

#### Q3: 车辆行进过程中出现低频“画龙”（S 型摇摆）？
> **排查方法**：典型的比例增益过大且相位滞后。应降低转向环比例项 `Pid_turn.Kp`，并相应提高角速度阻尼系数 `kd2`。

#### Q4: 环岛在出环或入环时异常打手，导致脱轨冲出？
> **排查方法**：连接无线串口输出 `Island_State`。重点排查状态未正常跃迁的原因：通常为拐点阈值在当前赛道反光下失效，或是补线斜率正负符号配置相反。
